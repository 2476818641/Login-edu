# 抓包交付处（captures/）

这个目录是**抓包的投放点**：你把 Burp 导出的 XML（或手抄报文）放进来，我按 `AI-PROMPT.md` 的那套格式分析，
然后改 `campus-portal-auth.sh` 的 3 处 `← 抓包` 填空。

> 只放抓包文件，不要提交进 git：本目录的 `.gitignore` 会挡掉除文档以外的一切文件。
> 抓包里含**明文密码、学号、会话 cookie**，属于敏感数据。

## 一、放哪里

| 位置 | 用途 |
|---|---|
| `/tmp/campus-capture/`（本机，推荐） | 直接丢 XML 进去，告诉我文件名，我来分析 |
| `openwrt/captures/`（本仓库） | 同上，适合你手上就有这份克隆；被 gitignore，不会推上去 |

文件命名建议：`<学校简称>-<日期>-<有线|无线>.xml`，例如 `xxu-20260920-wired.xml`。
旁边顺手放个只读文本 `说明.txt` 更好：这次是接网线还是连 Wi-Fi、账号类型（学号/一卡通号）、有没有先看到认证页。

## 二、抓包要求（决定成败的只有 3 件事）

1. **从"还没认证"的状态开始抓**：先断线（拔网线 / 断开 Wi-Fi / 路由器上 `ifdown wan`），再开 Burp，再插上/连上。
2. **故意输错一次密码，再输对一次** —— 有成功/失败对照，判定条件才可靠；只有成功样本时只能靠"外网通不通"兜底，容易误判。
3. **只留认证过程的流量**：登录完成、外网已通之后就可以停 Burp 了。刷论坛/看视频的流量会把 XML 撑到几十 MB，还会把真正的认证条目淹掉。

## 三、怎么导出（Burp）

Burp → **Proxy → HTTP history** → 在列表里框选（或 `Ctrl+A` 全选）→ 右键 → **Save items** → 保存为 `.xml`。
导出后在 Burp 里快速自检：

- 有没有一条 **POST**，目标是一个内网地址（`10.x` / `172.16~31.x` / `192.168.x` / `100.64~127.x`）？
- 有没有 **302 + Location** 指向认证页？→ 说明门户是"劫持重定向"型，很常见。
- 那条 POST 的响应里，成功和失败是不是不一样？把两条响应的原文都留着。

## 四、我要从抓包里取出的 6 样东西

| # | 要什么 | 从哪儿看 | 缺了会怎样 |
|---|---|---|---|
| 1 | 认证接口完整 URL（含 query） | POST 行的 Request line | 直接没法写脚本 |
| 2 | POST 的字段名和值来源 | POST body（`user_name=` / `user_pwd=` / `nasip=` …） | 字段名猜错 → 服务端返回"参数错误" |
| 3 | 是否需要先 GET 拿 cookie/token | POST 之前有没有 GET，POST 里带没带 Cookie | 少一步 → 登录被拒 |
| 4 | 成功的响应特征 | 输对那次响应 | 判定不准 → 反复重试/误报成功 |
| 5 | 失败的响应特征 | 输错那次响应 | 同上 |
| 6 | 密码是否加密 / 有无心跳 | 有没有 `*.js` 里算密码；有没有周期性请求 | 加密没处理 → 永远登不上；缺心跳 → 几分钟后被踢 |

抓包页面上如果还看到认证页的 HTML（响应里有 `<form action=...>`），那是最有价值的附赠品——字段名一清二楚。

## 五、先压缩再贴给 AI（可选，但强烈建议）

Burp XML 动辄几十 MB，任何在线 AI 都塞不进去。先跑压缩脚本，把"像认证流量"的条目抽出来、base64 解码、
cookie/密码值脱敏，输出几 KB 的 Markdown：

```sh
python3 openwrt/tools/burp-xml-summary.py captures/xxu-20260920-wired.xml -o captures/小抄.md
# 想看全部条目（不筛选）：加 --all
# 想让 cookie/密码值也保留（只给本地模型用时）：加 --no-redact
```

输出的小抄分 5 节：POST 目标 / 跳转 Location / 成功失败字样 / 认证页表单字段 / 逐条明细。
脱敏规则：请求体里的密码/令牌值 → `<已脱敏 N 字符>`，账号 → `<账号 N 位数字>`（`user@域名` 保留域名，有些学校认证要求带后缀）；
**响应体保持原文** —— 成功/失败判定串必须逐字保留，改了就写不成 `case` 模式了。cookie 只留名字、不留值。

压缩完把小抄 + `AI-PROMPT.md` 里的提示词一起贴给任意 AI，再把它的 A~F 六段发我；或者直接把小抄发我，我来做。

## 六、抓不到认证流量怎么办

- **认证页打不开**：确认电脑插在路由器的 **LAN 口**（lan1~lan3），WAN 口是给校园网网线用的；此时外网不通是正常的。
- **没有 302 劫持**：直接手动打开认证页（问同学/看辅导员发的地址，或看 DHCP 下发的 DNS 提示页）。
- **全是 HTTPS 且解不开**：需要在客户端装 Burp 证书（Proxy → Options → Import/export CA certificate → 装到"受信任的根"）。
- **学校用 802.1X（WPA-Enterprise）而不是网页认证**：那不在本脚本范围内，抓包也抓不到 HTTP 登录——告诉我，改走 `wpa_supplicant` 方案。
